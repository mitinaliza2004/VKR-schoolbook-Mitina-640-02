# VKR-schoolbook-Mitina-640-02
Репозиторий содержит материалы выпускной квалификационной работы, посвящённой разработке интеллектуального учебного пособия по профессиональному иностранному языку для студентов-медиков. Здесь хранятся исследовательская документация, результаты анализа, материалы проектирования, программная реализация прототипа и результаты его апробации.

**Структура репозитория:**

README.md — описание проекта.

Анализ средств управления проектами.docx — анализ инструментов и методологий управления проектом.

status-report.md — текущий статус исследовательского проекта: план, фактическое выполнение и риски.
