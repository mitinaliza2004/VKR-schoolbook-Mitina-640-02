# Статус-отчёт по исследовательскому проекту

**Проект:** Разработка интеллектуального учебного пособия по профессиональному иностранному языку для студентов-медиков.

**Дата составления отчёта:** 22 ноября 2026 г.

## 1. План проекта

Исследовательский проект разделён на шесть основных этапов:

| Этап | Планируемые работы | Плановый срок |
|---|---|---|
| 1. Старт исследования | Определение актуальности, проблемы, цели, задач, объекта и предмета исследования, утверждение структуры ВКР | Сентябрь – октябрь 2026 |
| 2. Теоретическая глава | Анализ профессионального английского языка для медиков, существующих пособий и цифровых ресурсов, обоснование требований к интеллектуальному пособию | Октябрь 2026 |
| 3. Проектирование | Проведение опроса студентов и интервью с преподавателями, разработка критериев оценки упражнений, выбор технологий и проектирование архитектуры пособия | Ноябрь 2026 |
| 4. Разработка прототипа | Подготовка базы медицинских текстов, реализация генерации упражнений, cloze-тестов, вопросов по тексту и проверки ответов | Декабрь 2026 |
| 5. Эмпирическая часть | Анкетирование студентов, интервью с преподавателями, экспертная оценка упражнений и usability-тестирование | Декабрь 2026 |
| 6. Подготовка второй главы и результатов | Анализ собранных данных, описание проектирования и разработки пособия, представление результатов исследования | Январь – февраль 2027 |
| 7. Подготовка полного текста ВКР | Завершение полного текста работы, проверка оригинальности в системе «Антиплагиат», устранение заимствований и передача текста научному руководителю | После завершения основных исследовательских этапов
|  8. Подготовка к предзащите | Подготовка доклада и презентации, участие в предзащите, устранение замечаний комиссии | Перед защитой ВКР |
| 9. Защита ВКР | Подготовка пакета документов, проведение 2–3 репетиций доклада и защита выпускной квалификационной работы | Подготовка полного текста ВКР |

## 2. Фактическое выполнение работ

По состоянию на 22 ноября 2026 года достигнуты следующие результаты:

- Завершён стартовый этап исследования: определена актуальность и проблема работы, сформулированы цель, задачи, объект и предмет, утверждена структура ВКР.
- Подготовлена первая глава ВКР, посвящённая теоретическим основам разработки интеллектуального учебного пособия.
- Проведён анализ особенностей профессионального английского языка для медицинских специалистов и существующих учебных пособий и цифровых ресурсов.
- Сформированы первоначальные представления о требованиях к разрабатываемому учебному пособию.
- Создан проект на GitHub Projects, в котором задачи распределены по шести основным этапам с указанием сроков и текущих статусов.

Согласно данным GitHub Projects, стартовый этап завершён полностью (3 из 3 задач). В теоретической главе отмечено выполнение 2 из 6 подзадач, остальные задачи имеют статусы In Progress и Todo. При этом первая глава уже подготовлена, поэтому необходимо актуализировать статусы доски в соответствии с фактическим состоянием работы.

Проектирование пособия, разработка программного прототипа и эмпирическая проверка находятся на этапе планирования. Основные задачи этих этапов пока имеют статус Todo.

## 3. Основные риски проекта

В ходе реализации исследовательского проекта можно выделить следующие риски:

**1. Задержка разработки программного прототипа.** Реализация генерации упражнений, проверки ответов и обработки медицинских текстов может потребовать больше времени, чем предусмотрено планом. Для снижения риска необходимо разделить разработку на небольшие функциональные модули и проверять каждый из них отдельно.

**2. Недостаточное количество участников эмпирического исследования.** Для получения репрезентативных результатов планируется привлечь не менее 30 студентов. Недостаточная активность респондентов может затруднить оценку эффективности пособия. Для предотвращения проблемы необходимо заранее подготовить анкету и организовать распространение опроса.

**3. Сложности с экспертной оценкой.** Проведение интервью с преподавателями и получение экспертной оценки упражнений зависит от доступности специалистов. Рекомендуется заранее согласовать сроки интервью и предусмотреть возможность привлечения дополнительных экспертов.

**4. Несоответствие функциональности пособия потребностям целевой аудитории.** Разработанные упражнения могут оказаться недостаточно удобными или не полностью соответствовать уровню подготовки студентов-медиков. Для снижения риска необходимо учитывать результаты анкетирования, интервью и usability-тестирования при корректировке прототипа.

**5. Нарушение сроков выполнения проекта.** Некоторые этапы разработки и эмпирического исследования выполняются параллельно, что может привести к перегрузке и задержкам. Для минимизации риска необходимо регулярно отслеживать сроки в GitHub Projects, выделять приоритетные задачи и корректировать последовательность работ при необходимости.

## 4. Общая оценка состояния проекта

На текущий момент исследовательский проект находится на переходе от теоретического этапа к проектированию и практической разработке интеллектуального учебного пособия. Основная теоретическая работа выполнена, сформирована структура дальнейшего исследования и определены направления разработки программного прототипа.

Ключевыми задачами ближайшего периода являются подготовка инструментов эмпирического исследования, выбор технологического стека, проектирование архитектуры пособия и начало разработки его основных функциональных модулей.

Для обеспечения своевременного завершения ВКР необходимо соблюдать установленные сроки, регулярно обновлять статусы задач в GitHub Projects и учитывать выявленные риски при планировании дальнейшей работы.
